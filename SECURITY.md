# Security Policy

This is a personal static-site dashboard. It has no user-facing service,
no authentication, and no PII beyond what the site author publishes.

## Reporting a vulnerability

If you find a security issue — e.g. a leaked credential in a build
artifact, an XSS in the inlined news renderer, or a way to crash the
build pipeline — please report it privately via GitHub's "Report a
vulnerability" button (Security tab) rather than opening a public issue.

I aim to acknowledge within 7 days. There is no bug bounty.
